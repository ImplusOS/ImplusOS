# QEMU テスト用ディレクトリの使用手順

> ⚠ 注意
> 以下の手順を実行することで発生した損害について、当方は一切責任を負いません。自己責任で実行してください。

## 手順

1. **Test ディレクトリを開く**
   まず、作業対象となる `Test` ディレクトリを開きます。

2. **必要なファイルを準備する**

   * QEMU を入手します。
   * `OVMF_CODE.fd` を入手します。
   * 両方のファイルを `Test` ディレクトリに配置します。

3. **OS 起動スクリプトを実行する**

   * Windows の場合：`Windows.bat` を実行
   * Linux / macOS の場合：`Debian_Linux.sh` 又は `macOS.sh` を実行

4. **テスト開始**
   スクリプトを実行すると、テストが開始されます。

## 補足

* スクリプト実行中に問題が発生した場合、作業を中止してください。
* OS や QEMU のバージョンによっては、追加の設定が必要な場合があります。
